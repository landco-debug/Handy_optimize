# 00 — НАЧНИТЕ ОТСЮДА

## Текущее состояние проекта

В этом репозитории есть только **две версии, которые следует считать полезными**:

1. **`main`** — текущая рабочая версия: **V4 + Lazy Settings Window**.
2. **`backup-v4-before-v5-memory`** — контрольная базовая **V4** до экспериментов с жизненным циклом окна.

Все остальные экспериментальные ветки являются устаревшими и **не должны использоваться как база для дальнейшей разработки**.

## Что считать мусором

Список устаревших веток находится здесь:

**`ZZZ_TRASH_DO_NOT_USE/README.md`**

Эти ветки были экспериментами вокруг:
- destroy/recreate settings WebView;
- автоматического restart при закрытии окна;
- исправлений V5/V5.1/V5.2.

Они сохранены только как исторические названия и не должны использоваться для новых изменений.

## Что читать новому ассистенту или разработчику

В таком порядке:

1. Этот файл — `00_START_HERE_RU.md`
2. `docs/ASTRA_ARCHITECTURE_AUDIT_RU.md` — итоговый архитектурный аудит
3. `docs/ASTRA_HANDOFF_REPORT_RU.md` — подробная история экспериментов и измерений
4. Только после этого — код `main`

## Принятое архитектурное решение

Оставлен вариант:

**V4 + Lazy Settings Window**

То есть:
- при скрытом старте settings WebView не создаётся;
- фоновая диктовка и hotkeys работают без settings window;
- после первого открытия окно при закрытии скрывается, а не уничтожается;
- автоматический full restart при каждом закрытии отвергнут как нестабильный;
- destroy/recreate settings WebView также не принят как основной путь.

Приоритеты проекта:

**стабильность > простота сопровождения > низкая память > сложность реализации**

## Важное предупреждение о настройках

Все тестовые сборки используют bundle identifier:

`com.pais.handy`

и поэтому разделяют один persistent store:

`settings_store.json`

Изменение настроек одной сборкой может повлиять на другую сборку.

Особенно важно проверять:
- `keyboard_implementation`
- `overlay_style`
- `start_hidden`
- `show_tray_icon`
- `model_unload_timeout`

## Как собирать

Для тестовой Apple Silicon сборки использовать:

**GitHub Actions → Build Test → branch: `main`**

Не использовать экспериментальные ветки из TRASH.
